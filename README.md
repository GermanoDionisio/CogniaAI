# Cognia AI Studio

Prompt para o Lovable

Desenvolva uma aplicação web completa chamada Cognia AI, inspirada na experiência do ChatGPT, Claude e Perplexity, porém com identidade visual própria, moderna e altamente profissional.

O objetivo é criar uma IA conversacional de nível profissional, com foco em produtividade, programação, estudos, pesquisa, criação de conteúdo e automação.

Objetivo

Criar uma plataforma de Inteligência Artificial premium, responsiva e escalável, oferecendo uma experiência semelhante às melhores plataformas de IA do mercado.

A interface deve transmitir confiança, tecnologia e simplicidade, utilizando um design minimalista de alto padrão.

Resultado esperado

O resultado deve ser uma aplicação completa chamada Cognia AI, com aparência profissional, interface refinada, arquitetura moderna e preparada para integração com provedores de IA (como OpenAI, Anthropic, Google, OpenRouter ou outros). A plataforma deve oferecer uma experiência de uso fluida e organizada, incluindo chat, histórico, upload e análise de documentos, geração e edição de imagens, exportação de conteúdo e respostas bem formatadas. A implementação deve respeitar as capacidades reais dos modelos e APIs integrados, sem prometer funcionalidades que dependam de serviços externos ainda não configurados.
